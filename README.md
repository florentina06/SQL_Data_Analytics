This project builds on my SQL Data Warehouse project and is split into two parts, matching the scripts:

- Exploratory data analysis (scripts 01 to 06): getting to know the data, starting with the tables and dates, then moving on to key totals and top performers
- Advanced analytics (scripts 07 to 13): digging deeper into trends over time, running totals, performance, part-to-whole and segmentation. The project ends with two reports, one on customers and one on products
